## ما هو تدوين؟

تدوين ليس نظام إدارة محتوى تقليديًا، بل لوحة تحكم بسيطة وجاهزة للإنتاج تتيح للعملاء غير التقنيين تعديل ملفات الماركداون خلف موقع Astro — ورؤية تغييراتهم مباشرة خلال ثوانٍ.

- **الماركداون هو قاعدة البيانات.** كل محتوى — تدوينات، مشاريع، أقسام الصفحة الرئيسية — ملف ماركداون عادي مع بيانات وصفية، محفوظ في Cloudflare R2. لا قاعدة بيانات معقدة، ولا احتكار للبيانات؛ محتواك دائمًا ملفات قابلة للنقل.
- **نشر فوري بدون إعادة بناء.** يعمل موقع Astro بوضع SSR على Cloudflare Workers ويقرأ الماركداون من R2 وقت الطلب خلف كاش Cloudflare. عند الحفظ يُمسح الكاش فيظهر التعديل مع التحديث التالي — بلا طوابير بناء ولا حيرة "لماذا لا أرى تعديلي؟".
- **عربي أولاً وثنائي اللغة تصميمًا.** واجهة اللوحة عربية RTL أصيلة مع دعم كامل للإنجليزية، وحقول المحتوى تُعرَّف كأزواج `ar`/`en` فتكون المواقع ثنائية اللغة هي الوضع الافتراضي.
- **نماذج مبنية على مخطط، لا منشئ صفحات.** أنت (المطوّر) تعرّف حقول كل نوع محتوى في ملف إعداد بسيط، فيحصل العميل على نماذج نظيفة مخصصة لا يمكنه كسرها.
- **يبقى Git لك.** لا يلمس العملاء المستودع أبدًا؛ الكود في Git والمحتوى في R2. لا حسابات GitHub ولا صداع صلاحيات.

## لمن هو؟

للوكالات والمستقلين الذين **يبيعون مواقع تسويقية بـ Astro** ويحتاجون لتسليم عملائهم طريقة بسيطة وآمنة لتعديل المحتوى — خصوصًا في الأسواق الناطقة بالعربية حيث تقصّر أنظمة إدارة المحتوى القائمة على Git في دعم RTL والمحتوى ثنائي اللغة.

## البدء السريع

```bash
npm create tadween-site my-site
cd my-site
npm install
npx tadween init        # تهيئة R2 وD1 ولوحة التحكم
npx tadween push-schema # رفع مخطط المحتوى
npm run dev
```

راجع [README.md](./README.md) للتوثيق الكامل بالإنجليزية.
